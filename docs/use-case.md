# Smart Library — Use Case

## Негізгі Use Case: Кітапты онлайн брондау және алу

Қатысушылар:
- Оқырман
- Кітапханашы
- Броньдау қызметкері
- Қор қызметкері
- Жүйелік әкімші
- Сайт әзірлеушісі

Негізгі процесс:
1. Оқырман кітапты іздейді.
2. Кітаптың қолжетімділігін тексереді.
3. Кітапты онлайн брондайды.
4. Жүйе броньды тіркейді.
5. Броньдау қызметкері жаңа броньды көреді.
6. Кітапты сөреден алып, бронь аймағына дайындайды.
7. Оқырман кітапханаға келеді.
8. Кітапханашы кітапты оқырманға береді.
## Қосымша мүмкіндік

Броньдау қызметкері броньдалған кітаптарды алдын ала дайындап, арнайы бронь аймағына орналастырады.
